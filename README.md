# Karatsuba Multiplication

Mini-project for Algorithms and Data Structures course.

## Structure

- src/karatsuba.py — Karatsuba algorithm
- src/naive.py — schoolbook multiplication
- tests/test_karatsuba.py — unit tests
- tests/benchmark.py — performance comparison

## Run tests

python -m unittest tests/test_karatsuba.py

## Run benchmark

python tests/benchmark.py
