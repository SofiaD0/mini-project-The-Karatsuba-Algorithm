# Karatsuba Multiplication Algorithm

Мини-проект по курсу «Алгоритмы и структуры данных».

## Обзор проекта

В данном проекте реализован алгоритм умножения Карацубы и выполнено его сравнение с классическим методом умножения.

Алгоритм Карацубы основан на принципе «разделяй и властвуй». Вместо выполнения четырёх рекурсивных умножений он выполняет только три, что позволяет уменьшить асимптотическую сложность с:

**Наивное умножение:** O(n²)

до

**Алгоритм Карацубы:** O(n^1.585)

## Идея алгоритма

Пусть даны два числа:

```text
x = a · 10^m + b
y = c · 10^m + d
```

В классическом рекурсивном подходе необходимо вычислить четыре произведения:

```text
ac, ad, bc, bd
```

Алгоритм Карацубы сокращает их количество до трёх:

```text
z0 = bd
z2 = ac
z1 = (a + b)(c + d) − z2 − z0
```

После этого результат восстанавливается по формуле:

```text
x · y = z2 · 10^(2m) + z1 · 10^m + z0
```

Такой подход приводит к рекуррентному соотношению:

```text
T(n) = 3T(n/2) + O(n)
```

что даёт асимптотическую сложность:

```text
O(n^1.585)
```

## Заключение
В ходе выполнения проекта был реализован алгоритм умножения Карацубы и проведено его сравнение с наивным алгоритмом умножения.

Корректность реализации была подтверждена с помощью набора модульных тестов, включающего как заранее известные примеры, так и случайно сгенерированные входные данные. Все тесты были успешно пройдены.

Экспериментальное исследование показало, что для чисел небольшой длины алгоритм Карацубы уступает наивному алгоритму по времени выполнения из-за дополнительных затрат на рекурсивные вызовы, разбиение чисел на части и выполнение вспомогательных операций. Однако с увеличением размера входных данных влияние этих накладных расходов уменьшается, и преимущество алгоритма Карацубы становится заметным.

Результаты измерений показали, что начиная примерно с 5000 цифр алгоритм Карацубы начинает превосходить наивный подход. Для чисел длиной 10000 цифр время выполнения составило 1,73 с против 4,53 с у наивного алгоритма. При дальнейшем увеличении размера входных данных разрыв становится ещё более существенным: для чисел длиной 20000 цифр алгоритм Карацубы оказался более чем в 5 раз быстрее, а для чисел длиной 50000 цифр — почти в 12 раз быстрее (16,5 с против 194,3 с).

Полученные результаты подтверждают теоретическое преимущество алгоритма Карацубы и его лучшую асимптотическую сложность O(n^1.585) по сравнению с наивным алгоритмом O(n^2). По мере роста размера входных данных выигрыш от уменьшения количества операций умножения становится всё более заметным.

Таким образом, поставленная цель проекта была достигнута: алгоритм Карацубы был успешно реализован, протестирован и экспериментально исследован. Проведённые эксперименты показали, что метод «разделяй и властвуй», лежащий в основе алгоритма Карацубы, обеспечивает значительное ускорение вычислений при работе с большими целыми числами и подтверждает практическую ценность алгоритмов с более эффективной асимптотикой.
